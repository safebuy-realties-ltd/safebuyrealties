1. Guest buyer journey

Browse → View details → Pay → Get access (no account required upfront)

flowchart LR
  A[Browse listings] --> B[View Property Details]
  B --> C{Choose action}
  C --> D[Start Due Diligence]
  C --> E[Schedule Inspection + fee]
  D --> F[Select 4 DD checks]
  E --> F
  F --> G[Order Summary + Service ID]
  G --> H[Pay: name / email / phone]
  H --> I[Success + email receipt]
  I --> J[Activate via email link]
  J --> K[Set password and login]

3. Seller & listing lifecycle

Draft stays private until verified and published

flowchart TD
  A[Seller Login] --> B[Create Draft listing]
  B --> C[Upload media + documents]
  C --> D[Submit for review]
  D --> E[PENDING_REVIEW]
  E --> F[Staff assigns professionals]
  F --> G[IN_VERIFICATION]
  G --> H{All steps accepted?}
  H -->|Yes| I[VERIFIED]
  H -->|No| J[REJECTED / revision]
  I --> K[Staff publishes]
  K --> L[LIVE + isPublished=true]
  L --> M[Visible on public Browse]
  B -.->|Never public| N[DRAFT hidden]
