The eighteenth thing, which is on nobody's board

ADR-0006 · 31 files under src, backend and scripts still name Vercel

ADR-0006 takes the platform off Vercel onto self-managed Nigerian infrastructure. That decision released D4 and it also bought work, and not one of the forty-two rows above pays for it. The list below is what a search of the working tree turns up, checked file by file rather than estimated.

Off Vercel there is no build hook to carry it, so the release procedure has to be written rather than inherited.
